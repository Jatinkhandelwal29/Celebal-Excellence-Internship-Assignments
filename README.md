# Celebal Technologies Internship Project

## Notebook Access Information

GitHub may occasionally be unable to render Jupyter Notebook (`.ipynb`) files directly, particularly when they contain extensive outputs or exceed GitHub's preview limitations.

If the notebook preview does not load, you can still access the complete project by following these steps:

1. Open the notebook file in this repository.
2. Click **Raw** to download the `.ipynb` file.
3. Open the downloaded notebook using **Jupyter Notebook**, **JupyterLab**, **Google Colab**, or **Visual Studio Code**.

The notebook has been tested and includes the complete implementation, source code, outputs, visualizations (where applicable), and project documentation.

**Note:** Any preview issue is caused by GitHub's rendering limitations and does not affect the functionality or completeness of the notebook.
